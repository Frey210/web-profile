# Airport Electronic QA Assets

Upload aset ke subfolder:

- `cover/cover.png`: foto utama airport electronics yang aman dipublikasikan.
- `diagrams/system-scope.png`: cakupan Cisco, BHS PLC/SCADA, FAS, PAS, HBS.
- `diagrams/qa-workflow.png`: alur QA commissioning.
- `photos/network-rack.jpg`: rack atau panel jaringan yang sudah disensor.
- `photos/scada-panel.jpg`: HMI/SCADA atau panel BHS jika aman.
- `photos/fire-alarm-panel.jpg`: panel FAS jika aman.
- `docs/commissioning-checklist-redacted.png`: checklist yang sudah disensor.

Jangan upload layout keamanan, IP address, dokumen kontrak, atau data internal bandara.
