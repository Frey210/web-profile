# Monitoring Platform Assets

Upload aset ke subfolder:

- `cover/cover.png`: Grafana atau status page.
- `screenshots/grafana-overview.png`: dashboard utama.
- `screenshots/server-health.png`: CPU/RAM/disk/network.
- `screenshots/docker-containers.png`: cAdvisor/container metrics.
- `screenshots/public-status-page.png`: status page.
- `screenshots/alert-example-redacted.png`: contoh alert yang disensor.
- `diagrams/monitoring-architecture.png`: exporters -> Prometheus -> Grafana.
- `diagrams/deployment-topology.png`: Docker, Nginx, Cloudflare Tunnel.
- `docs/prometheus-rule-redacted.png`: rule alert yang aman.

Sensor hostname, IP, token, nama client, dan URL private.
